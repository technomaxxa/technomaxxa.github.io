CURRENT FOCUS · v1.0.0 RELEASE

PyX Compiler

PUBLIC · GITHUB

A Python-inspired programming language and custom compiler built in Python. The project includes a lexer, parser, AST, semantic analyzer, type system, intermediate representation, custom bytecode, and a virtual machine. It is the project I use to study programming-language and compiler architecture by actually implementing the pipeline.

Python Compiler Design AST Type System Bytecode Virtual Machine
